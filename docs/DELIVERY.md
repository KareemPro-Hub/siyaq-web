# سِياق — حزمة التسليم

- الموقع: https://www.mysiyaq.com
- البريد: contact@mysiyaq.com
- المستودع: https://github.com/KareemPro-Hub/siyaq-web

## التعريف

سِياق موقع عربي لمراجعة الاقتباس القرآني. تكتب الاقتباس أو تستخرجه من صورة، فيحدد موضعه في المصحف، ويعرض:
- النص الأصلي.
- الآيات المحيطة به.
- التفسير الأصلي المتاح، مع مرجعه ورابط موضعه.

الهدف أن تُقرأ الآية في سياقها قبل الاقتباس، وأن يعود القارئ إلى مصدرها.

النسخة الحالية مخصصة للاقتباسات القرآنية. الأحاديث النبوية الموثقة توسع لاحق. تطبيق سِياق للآيفون أُرسل إلى Apple للمراجعة، ويستخدم خدمة المراجعة نفسها.

## المميزات الموجودة فعلًا

- **البحث في القرآن كاملًا:**
  - ٦٢٣٦ آية من الموسوعة القرآنية (مصحف حفص).
  - يقبل التشكيل أو عدمه، ويطابق حتى ثلاث آيات متجاورة.
- **تعدد المواضع:** تُعرض المواضع ليختار الباحث، دون اختيار تلقائي.
- **التشابه والأخطاء القريبة:** تُعرض «مواضع محتملة» للمقارنة مع إبراز الفروق، ولا تُعرض مطابقةً مؤكدة.
- **ثلاثة أقسام لكل نتيجة:** النص القرآني، والسياق المحيط، والتفسير ومصدره.
- **التفسير الأصلي:**
  - من تفسير مجاهد (ت ١٠٤هـ) وتفسير سفيان الثوري (ت ١٦١هـ)، وهما من مصادر القرون الثلاثة الأولى في المرجعية المعتمدة.
  - روابط مباشرة إلى الآية وإلى تفسيرها في الكتاب نفسه.
  - إذا غاب التفسير يظهر الغياب صراحة، ولا يُعرض تفسير آية أخرى.
- **قراءة الصور:**
  - تجري داخل المتصفح، والصورة لا تُرفع.
  - النص المستخرج مسودة تعدّلها قبل البحث، والبحث لا يبدأ إلا بضغطك.
- **مساعد سِياق — تجريبي:**
  - زر «تحدث مع سِياق» يفتح مساعد استقبال وتوجيه بالصوت والكتابة.
  - يجيب عن استخدام الموقع من ردود معدّة ومراجَعة مسبقًا.
  - ينفذ خطوات حقيقية: الانتقال إلى مربع الاقتباس، وقارئ الصور مع زر اختيار الصورة، وصفحات المصادر وكيف يعمل والدعم والخصوصية، وتبويبي السياق والتفسير في النتيجة المختارة.
  - يتيح إملاء الاقتباس، ويعرض النص كما سُمع لتصحّحه قبل المراجعة.
  - لا يولّد آيات أو تفسيرًا أو فتاوى.
- **أدوات أخرى:** نسخ النص والمرجع، وصفحات المصادر والمنهجية والدعم والخصوصية.
- **عند ضعف الاتصال:** رسائل واضحة مع «إعادة المحاولة»، والاقتباس يبقى كما هو. الكتابة اليدوية متاحة دائمًا إذا تعذرت قراءة الصورة.

## الحدود

- **الذكاء الاصطناعي مستخدم في موضعين:**
  - قراءة الصور داخل المتصفح.
  - تحويل الكلام إلى نص في مساعد سِياق، عبر خدمة التعرف على الكلام في متصفح الزائر. في Chrome يُرسل الصوت إلى خدمة Google للتعرف.
- **ما ليس ذكاءً اصطناعيًا:**
  - تحديد الموضع مقارنة نصية.
  - التفسير مسترجع من مصادره، وتوليد الشرح معطّل.
  - اختيار رد المساعد قواعد كلمات مفتاحية تختار من ردود مكتوبة مسبقًا، وليس نموذجًا مدرّبًا ولا مساعدًا شرعيًا.
- **صوت المساعد:**
  - يعتمد على المتصفح والجهاز: في Safari يعمل التعرف بمحرك Siri ويحتاج تفعيله، وفي Firefox لا يكون مفعّلًا افتراضيًا، فيعمل المساعد بالكتابة.
  - إذا لم يتوفر صوت عربي، تظهر الردود مكتوبة.
  - لا يُحفظ التسجيل ولا المحادثة.
- **تغطية التفسير جزئية:** ١٨٣٤ موضعًا.
- **الاقتباس:** كلمتان على الأقل، وحتى ١٠٠٠ حرف؛ يمكن مراجعة جزء من الآية الطويلة.
- **قراءة الصور:** قد تخطئ في الصور الرديئة أو الخطوط المزخرفة.
- **عدم العثور:** لا يكفي وحده للحكم على أصل النص.
- **ما لا يقدمه سِياق:** لا فتوى، ولا تصحيح لأسانيد الروايات، ولا تفسير مولّد.
- **البحث يحتاج اتصالًا بالإنترنت.**

## خطوات التجربة

افتح https://www.mysiyaq.com ثم:

1. اكتب «لا تقربوا الصلاة»، ثم اضغط «راجع الاقتباس».
   - تظهر سورة النساء، الآية ٤٣.
   - في تبويب «التفسير ومصدره»: نصوص من تفسير مجاهد والثوري، مع رابط كل منها.
2. اكتب «فبأي آلاء ربكما تكذبان».
   - تظهر مواضع متعددة في سورة الرحمن لتختار منها، ولا يُختار موضع تلقائيًا.
3. اكتب «الحمد لله رب العالمين الرحمن الرحيم».
   - يظهر اقتباس يمتد على آيتين متجاورتين (الفاتحة ٢–٣).
4. اكتب نصًا فيه أخطاء، مثل «ولا تقربوا الصلوه وانتم سكري حتي تعلموا ما تقولون».
   - تظهر «مواضع متشابهة»، وبعد الاختيار «موضع محتمل» مع مقارنة الألفاظ.
5. اكتب «ولا تحسبن الله غافلا عما يعمل الظالمون» (إبراهيم ٤٢).
   - في التفسير يظهر الغياب صراحة، مع رابط مقطع الآيات ٤٢–٤٦ في الدرر السنية.
6. اكتب «مهطعين مقنعي رءوسهم» (إبراهيم ٤٣).
   - تظهر نصوص التفسير من الكتابين، وكل رابط يفتح الآية ٤٣ في الكتاب المحدد.
7. اضغط «اقرأ من صورة» واختر لقطة لآية.
   - يظهر النص في المربع لتراجعه.
   - البحث لا يبدأ إلا بضغطك.
8. اكتب جملة ليست من القرآن.
   - تظهر رسالة «لم نعثر على موضع يمكن تأكيده»، دون آية أو تفسير بديل.
9. في قسم النص القرآني اضغط «نسخ النص والمرجع».
10. راجع صفحات «المصادر» و«كيف يعمل» و«الدعم» و«الخصوصية» من روابط تذييل الصفحة.
11. اضغط «تحدث مع سِياق» أسفل الصفحة.
    - يظهر «مساعد سِياق — تجريبي» ويرحب بك.
    - اختر «كيف أستخدم صورة ؟»، أو اكتب «أريد مراجعة اقتباس» فينتقل التركيز إلى مربع الاقتباس.
    - في Chrome اضغط «تحدّث» وقل «أريد المصادر»، فتُفتح صفحة المصادر.
    - بعد مراجعة «لا تقربوا الصلاة» قل أو اكتب «افتح التفسير»، فيُفتح تبويب التفسير.

## التشغيل من GitHub

المتطلبات:
- Node.js 22 أو أحدث.
- Python 3، لأمر التحقق من البيانات فقط.

لا يلزم أي مفتاح أو خدمة مدفوعة أو ملف بيئة.

```sh
git clone https://github.com/KareemPro-Hub/siyaq-web.git
cd siyaq-web
npm ci
npm run dev
```

افتح http://127.0.0.1:3000

التحقق ونسخة الإنتاج:

```sh
npm test            # اختبارات الوحدة والخدمة
npm run typecheck
npm run data:verify # يتحقق من ٦٢٣٦ آية و١١٤ سورة وبصمات البيانات
npm run build
npm run start       # http://127.0.0.1:3000
```

خدمة المراجعة لتطبيقات أخرى:
- `POST /api/review`، بصيغة JSON: `{"quote": "لا تقربوا الصلاة"}`.
- العقد كاملًا في `docs/API.md`.
