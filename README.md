# سِياق — فهم وتوثيق

موقع عربي يراجع الاقتباسات القرآنية ويعرض النص الأصلي، والسورة والآية، والسياق المحيط، والتفسير المتاح مع مرجعه ورابطه المباشر. يتضمن قراءة النص العربي من الصور داخل المتصفح.

الموقع: https://www.mysiyaq.com — الدعم: contact@mysiyaq.com

هذا مستودع كود الموقع وملفات تشغيله. النسخة الحالية للآيات القرآنية؛ التوسع إلى الأحاديث الموثقة مخطط لاحقًا. تطبيق الآيفون منفصل عن هذا المستودع، وقد متاح مجانًا على App Store.

## التشغيل المحلي

المتطلبات: Node.js 22 أو أحدث وnpm. يلزم اتصال لتنزيل الاعتماديات أول مرة. البيانات والخطوط ومحرك قراءة الصور موجودة في المستودع؛ لا يحتاج التشغيل إلى حساب أو مفتاح لخدمة ذكاء اصطناعي.

```sh
git clone https://github.com/KareemPro-Hub/siyaq-web.git
cd siyaq-web
npm ci
npm run dev
```

افتح http://127.0.0.1:3000 . لتشغيل نسخة الإنتاج محليًا:

```sh
npm run build
npm run start
```

على macOS يمكن فتح `تشغيل-سياق.command` بعد تثبيت Node.js. أو استخدم الأوامر السابقة على أي نظام يدعم المتطلبات.

## الفحص

```sh
npm test
npm run build
npm run typecheck
```

للتحقق من بصمات البيانات وبنيتها، يلزم Python 3:

```sh
npm run data:verify
```

لفحص OCR والبحث في المتصفح: شغّل نسخة الإنتاج ثم، في نافذة أخرى:

```sh
SIYAQ_QA_URL=http://127.0.0.1:3000 node scripts/browser-free-qa.mjs
```

يستخدم الفحص Google Chrome على macOS افتراضيًا. يمكن تحديد ملف Chromium التنفيذي عبر `SIYAQ_QA_BROWSER`، وحفظ الأدلة عبر `SIYAQ_QA_DIR`.

## المميزات والحدود

- مطابقة الاقتباس بالنص القرآني مع عرض المواضع المحتملة للاختيار.
- عرض النص الأصلي والسياق، والتفسير الأصلي المتاح من كتابي مجاهد وسفيان الثوري.
- روابط مباشرة للآية في المصدر، وتوثيق الكتاب والجزء والصفحة عند توفرها.
- قراءة صور PNG وJPEG وWebP داخل المتصفح، ثم مراجعة النص المستخرج قبل البحث.
- نسخ النص والمرجع، وواجهة عربية RTL ودعم تقليل الحركة.
- «مساعد سِياق — تجريبي»: توجيه بالصوت والكتابة عن استخدام الموقع من ردود معدّة مسبقًا، مع إجراءات محددة داخل الموقع. التعرف على الكلام من متصفح الزائر، واختيار الرد بقواعد كلمات وليس بنموذج مدرّب. التفاصيل في [docs/ASSISTANT.md](docs/ASSISTANT.md).
- لا تفسير مولد ولا فتوى آلية. `/api/explain` يحتفظ باستجابة الامتناع للتوافق؛ لا يستدعي مزودًا خارجيًا في النسخة الحالية.

التفسير جزئي: ١٨٣٤ موضعًا و٢٨٦٨ نصًا. عند غيابه تُعرض الحالة بوضوح. المطابقة التقنية لا تصحح أسانيد الروايات ولا تمثل مراجعة علمية بشرية لكل رواية. شروط المصادر موثقة في [docs/SOURCES.md](docs/SOURCES.md) و[data/source-policy.json](data/source-policy.json).

## البيانات والتراخيص

مصدر البيانات: **الموسوعة القرآنية [Quranpedia.net](https://quranpedia.net)**، إصدار **2026-10-01**؛ ٦٢٣٦ آية و١١٤ سورة. النسبة والإصدار محفوظان وفق [رخصة البيانات](data/source/LICENSE.md)، والبصمات في [data/provenance.json](data/provenance.json). يتضمن هذا المستودع النص القرآني ونصوص التفسير المحددة؛ لا يتضمن بيانات التحليل الصرفي أو الإعراب ذات التراخيص المستقلة.

شهرزاد الجديد للواجهة والتفسير بأوزان ٤٠٠ و٥٠٠ و٧٠٠، وأميري قرآن للنص القرآني بوزن ٤٠٠؛ كلاهما برخصة SIL OFL 1.1 وبملفاته الأصلية المستضافة محليًا، ومحرك OCR ونماذجه برخص Apache-2.0. نصوص التراخيص محفوظة مع ملفاتها. راجع [docs/ASSETS.md](docs/ASSETS.md) و[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

إتاحة المستودع للمراجعة والتشغيل لا تمنح ترخيصًا عامًا لإعادة استخدام شعار سِياق وهويته. لا تُغيّر تراخيصُ المكونات الخارجية ملكيةَ بقية أجزاء المشروع أو تمنحها ترخيصًا مختلفًا.

## هيكل المشروع

- `src/app/`: الصفحات وواجهات الخدمة.
- `src/components/`: الواجهة وقراءة الصور.
- `src/lib/`: المطابقة والعقود وروابط المصادر.
- `data/`: البيانات وسجل المصدر والتراخيص.
- `public/`: أصول الهوية وOCR المرخصة.
- `src/content/assistant-responses.json`: ردود مساعد سِياق المعتمدة.
- `tests/`: اختبارات السلوك والبيانات.
- `docs/API.md`: عقد الخدمة المشتركة.

الصور لا تُرفع للخادم؛ يُرسل نص الاقتباس فقط عند طلب المراجعة. لا مفاتيح تشغيل ضمن المستودع. تظل سياسة الخصوصية متاحة داخل الموقع.

## فحص رحلات الاستخدام

بعد تشغيل نسخة الإنتاج محليًا على المنفذ 3000:

```sh
QA_URL=http://127.0.0.1:3000 node scripts/qa-delivery.mjs
```

يشمل البحث والصور وحالات فشل الاتصال والوصول ومقاسات الكمبيوتر والهاتف. يعمل Chrome مخفيًا؛ يمكن تحديد ملف المتصفح عبر QA_BROWSER ومجلد الأدلة عبر QA_OUT.

فحص مساعد سِياق: `QA_URL=http://127.0.0.1:3000 node scripts/qa-assistant.mjs`. الصوت فيه محاكاة داخل الصفحة لاختبار المنطق والواجهة، وليس تجربة تعرف صوتي حقيقية.

## الفهرسة في محركات البحث

الفهرسة مسموحة على https://www.mysiyaq.com للصفحات الخمس فقط: الرئيسية، والمصادر، وكيف يعمل، والدعم، والخصوصية، بلا معاملات في الرابط. نتائج المراجعة حالة مؤقتة داخل الرئيسية ولا تُنشئ روابط عامة، والاقتباس يُرسل في جسم الطلب فقط. الخدمة والمسارات الأخرى والروابط ذات المعاملات ورابط Vercel القديم ترسل noindex؛ ويظل رابط الخدمة القديم يعمل دون تحويل.

تجمع src/lib/seo.ts القواعد والعناوين والأوصاف والروابط الأساسية. robots.txt يتيح الزحف للصفحات ويمنع /api/، وخريطة sitemap.xml تسرد الصفحات الخمس على الدومين المعتمد. robots.txt وsitemap.xml ملفا اكتشاف تقنيان متاحان دون noindex على الدومين الأساسي وبلا معاملات، كي تقرأهما المحركات؛ لا يُعدان صفحتَي محتوى إضافيتين. السماح بالفهرسة لا يضمن ظهورًا أو ترتيبًا في نتائج البحث.

رمز ملكية Google Search Console يمكن وضعه في GOOGLE_SITE_VERIFICATION داخل src/lib/seo.ts؛ فارغًا لا تُضاف علامة تحقق. يُستخرج الرمز من حساب مالك الموقع؛ لا توجد بيانات دخول في الكود.

بعد بناء وتشغيل الموقع محليًا، يمكن فحص قواعد الفهرسة:

```sh
QA_URL=http://127.0.0.1:3000 node scripts/qa-seo.mjs
```

يستخدم Chrome مخفيًا على macOS افتراضيًا، ويمكن تحديد QA_BROWSER وQA_OUT. الفحص المحلي يمرر Host لاختبار الدومين المعتمد والرابط القديم دون زيارة الموقع المنشور.
